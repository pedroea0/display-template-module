# Click To Graph Chart events

The chart fires four component events. Configure them like any Perspective component event: right-click the
component > **Configure Events...**, pick the event under *Component Events*, and add an action.

**On this page**

- [Overview](#overview)
- [onPensChange](#onpenschange)
- [onRangeChange](#onrangechange)
- [onXTraceChange](#onxtracechange)
- [onBrushChange](#onbrushchange)

---

## Overview

| Event | When |
|---|---|
| `onPensChange` | a user added, removed or edited a pen at runtime |
| `onRangeChange` | the user changed the time range, zoomed or panned (debounced 500 ms) |
| `onXTraceChange` | pinned X-Trace cursors changed |
| `onBrushChange` | a range brush was added, changed or removed |

All chart events are fired **in the browser** and only for **user actions**: data refreshes, prop changes from bindings
or scripts, and anything in Designer design mode do not fire them. Script actions read the payload as attributes of
`event` (`event.tagPath`, `event.start`).

> **Important** Like every component event, their payloads can be imitated by a page script, so do not treat them as
> proof of anything and never let an event script do something the user may not do.

For state that bindings should follow (the visible window, the chart status, the effective pens), bind to
[`outputs`](README.md#outputs-for-bindings-and-scripts) instead of listening to events.

## onPensChange

Fires after a user adds, removes or edits a pen at runtime: tag browser **Add selected**, the pen table's trash icon,
the settings panel, *Clear list*.

<!-- BEGIN GENERATED: events ctgchart onPensChange -->
<!-- Generated by simple-tag-display/tools/gen-prop-docs.mjs from the schemas. Do not edit by hand. -->

Fired in the browser after a user adds, removes or edits a pen at runtime. Like every component event, this payload can be imitated by a page script; the audit log (auditId) is the authoritative record.

| Field | Type | Description |
|---|---|---|
| `action` | string | "add", "remove" or "edit". |
| `tagPath` | string | Full path of the pen tag. |
| `source` | string | "pens" (pens prop) or "trend" (session trend list). |

<!-- END GENERATED: events ctgchart onPensChange -->

Example: log pens users add.

```python
def runAction(self, event):
    if event.action == 'add':
        system.util.getLogger('Trends').info('pen added: %s (%s)' % (event.tagPath, event.source))
```

## onRangeChange

Fires 500 ms after the visible window stops changing: date range dialog, zoom, pan, reset zoom, return to live.

<!-- BEGIN GENERATED: events ctgchart onRangeChange -->
<!-- Generated by simple-tag-display/tools/gen-prop-docs.mjs from the schemas. Do not edit by hand. -->

Fired in the browser (debounced 500 ms) after the user changes the time range, zooms or pans. Like every component event, this payload can be imitated by a page script; the audit log (auditId) is the authoritative record.

| Field | Type | Description |
|---|---|---|
| `mode` | string | "realtime" or "historical". |
| `start` | number | Start of the visible window, epoch milliseconds. |
| `end` | number | End of the visible window, epoch milliseconds. |

<!-- END GENERATED: events ctgchart onRangeChange -->

Example: keep a second chart on the same window.

```python
def runAction(self, event):
    other = self.parent.getChild('DetailChart')
    other.props.timeRange.mode = 'historical'
    other.props.timeRange.historical.startDate = event.start
    other.props.timeRange.historical.endDate = event.end
```

## onXTraceChange

Fires when the user pins, moves or removes an X-Trace cursor (click in X-Trace mode, long-press or double-tap on
touch, Enter or Delete on the keyboard).

<!-- BEGIN GENERATED: events ctgchart onXTraceChange -->
<!-- Generated by simple-tag-display/tools/gen-prop-docs.mjs from the schemas. Do not edit by hand. -->

Fired in the browser when pinned X-Trace cursors change. Like every component event, this payload can be imitated by a page script; the audit log (auditId) is the authoritative record.

| Field | Type | Description |
|---|---|---|
| `times` | string | Comma-separated pinned cursor times, epoch milliseconds. |
| `count` | number | Number of pinned cursors. |

<!-- END GENERATED: events ctgchart onXTraceChange -->

Example: show the first pinned time in a label.

```python
def runAction(self, event):
    times = [long(t) for t in event.times.split(',') if t]
    self.parent.getChild('CursorLabel').props.text = (
        system.date.format(system.date.fromMillis(times[0]), 'HH:mm:ss') if times else '')
```

## onBrushChange

Fires when a range brush is added, moved, resized or removed (Range mode).

<!-- BEGIN GENERATED: events ctgchart onBrushChange -->
<!-- Generated by simple-tag-display/tools/gen-prop-docs.mjs from the schemas. Do not edit by hand. -->

Fired in the browser when a range brush is added, changed or removed. Like every component event, this payload can be imitated by a page script; the audit log (auditId) is the authoritative record.

| Field | Type | Description |
|---|---|---|
| `id` | string | Brush id. |
| `start` | number | Brush start, epoch milliseconds. |
| `end` | number | Brush end, epoch milliseconds. |
| `plot` | number | Index of the plot the brush is on. |
| `action` | string | "add", "change" or "remove". |

<!-- END GENERATED: events ctgchart onBrushChange -->

Example: remember the last selected range in a custom prop.

```python
def runAction(self, event):
    if event.action != 'remove':
        self.view.custom.selection = {'start': event.start, 'end': event.end}
```
