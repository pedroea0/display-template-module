# Click To Graph Chart properties

Every prop of the Click To Graph Chart, grouped by what it controls. Each group starts with a short explanation and an
example; the table under it lists **every** path in the group.

**How to read the tables**

| Column | Meaning |
|---|---|
| Prop | the path in the property tree; `[]` marks the items of an array (`pens[].color` is the colour of each pen) |
| Type | the JSON type; `string (colour)` takes any CSS colour, `style` is a Perspective style object (inline styles plus `classes`) |
| Default | the value a new component starts with; an empty cell on an object means "see its children" |
| Description | what it does, followed by the valid values (`One of …`, ranges, lengths) |

**[S]** marks a **security prop**: the gateway reads it from its own trusted copy and enforces it, so a change made in
the browser is put back and logged. See [Trusted props](../../security-and-permissions.md#trusted-props).

Many props are also changed **by the chart at runtime** (the toolbar writes `interaction.mode` and `timeRange`, the
settings panel writes `pens`, `axes`, `plots` and `penTable.columns`, the chart writes `outputs`). Those writes last for
the page; they are not saved into the view except in a Designer preview.

The tables are generated from the component's JSON schema (the same descriptions appear in the Designer's property
editor), so they always match the shipped module.

## Behaviour and title

`enabled: false` makes a viewing-only chart: data still loads and refreshes, zoom, pan, X-Trace, range brush, date
range and export work, but nothing that changes the configuration does. `title` adds a title row above the toolbar.

```json
"enabled": true,
"title": { "visible": true, "text": "Tank 1" }
```

## Pens

Pens configured in the Designer. Each pen is one tag with history; the chart adds the session trend list's pens after
them. A binding on `pens` is treated as configuration (outside the read scope). Guide:
[Pens, axes and plots](pens-axes-plots.md#pens).

```json
"pens": [
  { "tagPath": "[default]Area1/Tank1/Level", "name": "Level", "color": "#1F77B4", "axis": "Level" },
  { "tagPath": "[default]Area1/Pump1/Running", "plot": 1, "display": { "type": "step" } }
]
```

## Trend list

`trendGroup` picks the session trend list the chart shows (the one Display Templates add to with **Trend Tag**); empty
or `null` ignores it. `trendEdit` decides who may change that list from the chart. `trendPens` styles the pens that
come from the list: `defaults` for all of them, and `overrides`, written by the chart when a user restyles one.

```json
"trendGroup": "area1",
"trendEdit":  { "access": { "roles": ["Operator"] } },
"trendPens":  { "nameMode": "leaf", "defaults": { "display": { "width": 2 } } }
```

## Read scope

Which tags pens added **at runtime** (settings panel, tag browser, or a browser writing `pens`) may read. Configured
pens and the trend list are always allowed. Empty `allowedRoots` follows `tagBrowser.rootPath` while the tag browser is
enabled. Guide: [Read scope](README.md#read-scope-which-tags-a-chart-may-read).
